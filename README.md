# Customer Churn Prediction using Machine Learning

##  Project Overview

This project focuses on predicting customer churn for a subscription-based service or business using Machine Learning techniques.

The model uses historical customer data, including customer demographics and usage behavior, to identify customers who are likely to discontinue a service.

This project is completed as **Task 3** of the CODSOFT Machine Learning Internship.

##  Objectives

- Predict customers who are likely to leave a service.
- Analyze historical customer data.
- Understand customer behavior and patterns.
- Build Machine Learning classification models.
- Support customer retention strategies through predictive analysis.
